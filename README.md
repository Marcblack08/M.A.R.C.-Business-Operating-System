# M.A.R.C. — Reinicio arquitectónico

M.A.R.C. será un SaaS de operaciones empresariales con dos canales principales:

- Web
- Telegram

El núcleo compartirá identidad, datos, permisos, IA, historial y suscripción.

## Estructura funcional

Inicio → Clientes → Inventario → Cotizaciones → Comunicaciones → Configuración

La IA es transversal y no constituye un módulo independiente.

## Integraciones previstas

- Sakit
- Q
- Sumasa
- Clover

Cada integración requiere un contrato antes de implementarse.

## Monetización

M.A.R.C. se comercializará mediante planes de suscripción.
